# agent-charter

> 一套经过实战调校的 AI 协作框架，可一键铺到任意新仓库。

核心不是文件模板，而是四条被验证过的机制：**常驻文件冻结**（省钱）、**决策点序贯呈报**（不越步）、**分段执行**（不爆上下文）、**文档分层**（不腐烂）。

---

## 它解决什么问题

| 症状 | 根因 | 本框架的对策 |
|---|---|---|
| 规则写了一堆，AI 照样走错 | 规则是形容词，不可判定 | 每条规则配「自检判据」 |
| AI 自己往下干不停下来 | 缺决策契约与动手闸 | `AGENTS.md` §5 + `index.md` §8.8 |
| 常驻上下文越来越贵 | 项目内容塞进 `AGENTS.md` | L0/L1/L2 分层 + 检索表 |
| 长任务吃掉大量额度 | 单会话连跑到黑 | 分段 + 检查点 |
| 文档越写越多没人读 | 没有索引、没有归档规则 | `doc/` 目录归置 + 三分层 |

## 快速开始

把骨架铺到目标仓库：

```bash
# 默认档 0：只铺 AGENTS.md + index.md
python scripts/scaffold.py <目标仓库根目录> --minimal

# 全套骨架（档 1+）
python scripts/scaffold.py <目标仓库根目录>

# 只看会写什么，不落盘
python scripts/scaffold.py <目标仓库根目录> --dry-run
```

脚本特性：

- **幂等**：已存在的文件默认跳过（报告标 `SKIP`），要覆盖加 `--force`。
- **不删除**：只做新建与建目录，不清理任何已有内容。
- **先看后写**：`--dry-run` 输出完整写入清单。

铺完后必做：

1. 逐项填写 `index.md` 的 §0 填充清单，填完删掉该节。
2. 把 `doc/ref/build.md` 里每条命令**实跑一次**，改掉与实况不符的。
3. 走 `SKILL.md` 阶段 4 的四条自检。

## 档位：从最小可用开始，不要贪多

| 档 | 铺什么 | 何时升级 |
|---|---|---|
| **0 最小可用** | `AGENTS.md` + `index.md` | 默认起点 |
| **1 标准** | + `doc/` 骨架，填实 `ref/build.md`、`ref/project.md` | 有构建/部署链 |
| **2 议题化** | + 启用 `adr/`、`todo/`、`遗留问题.md` | 有 ≥2 人改、要留决策痕迹 |
| **3 沉淀化** | + 启用 `reuse/`、`research/`、`note/` | 经验开始重复出现 |

> 档 0 没落地就铺档 3 ⇒ 空目录变成文档债，反而降低信任。判据见 `references/adoption.md`。

## 目录结构

```
agent-charter/
├── SKILL.md                  # 技能入口：什么时候用、怎么执行、四条约束
├── README.md                 # 本文件
├── references/               # 深入阅读（按需）
│   ├── layers.md             # L0–L3 分层契约 + 省 token 四条
│   ├── patterns.md           # 11 条可复用范式
│   └── adoption.md           # 档位判据 / 新仓顺序 / 已有仓库迁移 / 失败模式
├── scripts/
│   └── scaffold.py           # 一键铺开（幂等 + dry-run）
└── templates/                # 铺到目标仓库的骨架
    ├── AGENTS.md             # L0 通用准则（逐字复制，勿改）
    ├── index.md              # L1 项目规则 + 检索表
    └── doc/                  # L2/L3 文档骨架
```

## 何时用 / 何时不用

**用**：

- 新仓开张，AI 要长期在这个仓干活。
- 已有仓的 AI 规则混乱、太长、总被绕过。
- 多个仓要统一 AI 工作方式（各仓 `AGENTS.md` 完全一致，只有 `index.md` 不同）。

**不用**：

- 一次性任务、临时脚本 —— 铺框架的成本高于收益。
- 只想改某条已有规则 —— 直接改那一条即可。

---

## 四条不能违反的约束

1. **不许把项目事实写成占位符交付**。宁可留 `{{TODO: 构建命令}}` 显式待办，也不编假命令。
2. **不许往 `AGENTS.md` 里塞项目内容**（它是每轮自动注入的常驻文件）。
3. **不许在有既有规则的仓里顺手重排编号**（规则编号常被外部文档引用）。
4. **不许跳过只读探测阶段**（照抄别的仓库的 `index.md` 是最常见的误用）。
