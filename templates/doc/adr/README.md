> **本文件 = 层 B 活文档，唯一的状态权威**。决策正文在 `NNNN-*.md`（**层 A 冻结快照，不回填**）。
> 分工：**正文答「当时决定了什么」，本文件答「现在还有效吗、被谁取代/扩展」** —— 因正文冻结、后续状态写不进去，**状态只能落在这里**。
> 新 ADR 编号 = **明细编号与下表编号的并集最大值 + 1**（防撞号）。

## 四、写法约定

- **一条 ADR 一个决策**，写"**为什么**"而非"改了什么"（改动看 commit）。
- 命名 `NNNN-中文标题.md`，4 位零填充；**不因状态流转迁移目录**。
- 新 ADR 推翻旧决策 ⇒ **必须在总表与关系图显式标注**；被取代文档同步标注并指向新方案。
- 正文落盘后**不回填**；后续变化一律走新 ADR + 状态表更新。
