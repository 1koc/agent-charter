# 项目文档索引

> 本索引覆盖 `doc/` 下的目录与文档，按「是否随代码演进」**三分层**（规范见 `index.md` §8）。
>
> **层 A｜冻结区（不回填、不维护）** —— 记录*当时*状态，失效链接**允许存在、禁止回填**（回填即篡改历史）：
> - `doc/adr/` 下的 `NNNN-*.md`（决策正文快照，**不含** `doc/adr/README.md`）、`doc/archive/`（已落地方案）、`doc/chaos/`（过程材料）、`doc/origin/`（原始资料，只读）。
>
> **层 B｜活文档（唯一维护区）** —— 保证 0 坏链、随代码同步：
> - `doc/collect/`、三个索引（本页 / `adr/README.md` / `todo/README.md`）、`doc/todo/遗留问题.md`、`doc/bug/`、`doc/reuse/`、`doc/note/`、`doc/ref/`、`doc/research/`。
>
> **层 C｜单一事实源（SSOT）** —— **分工两件套**：① 状态与取代/扩展关系唯一维护在 `doc/adr/README.md`（状态总表 + 关系图，**层 B 活文档**）；② 决策正文为 `doc/adr/NNNN-*.md`（**层 A 冻结快照**）。一句话：正文答「当时决定了什么」，README 答「现在还有效吗、被谁取代/扩展」。本页只放指针，**禁止两处维护同一内容**。
>
> **引用约定**（优先级 **符号 > 路径 > 行号**）：指源文件用**仓库相对路径**（禁 `file:///` 绝对链接）；指函数/逻辑用**符号定位**（`src/x.cpp :: Func()`）**不写行号**（行号仅在 ADR 作「当时快照」）；指契约字段**不抄清单**，写「见 `inc/Xxx.h` 的 `XxxStruct`」；跨文档不复制内容，链接 + 一句摘要。
>
> **`doc/` 根目录只允许 `README.md`**（本索引）；其余一切文档必须落子目录，归口见 `index.md` §8「目录归置硬约束」。

## 十一、要点记录（doc/note/）

> 承载**结论型短记录** —— 「某处被硬编码绑定」「某参数不可单边改」「某约束只能靠编译宏」这类**一句话要点 + 证据 + 影响 + 处置**。
> 一要点一 md、按内容命名；属**层 B 活文档**。与 `doc/bug/`（缺陷修复记录）、`doc/todo/`（演进方案）分工不同。

---

## 十二、前置调研（doc/research/）

> 承载**前置调研 / 可行性 / 能力边界**类文档 —— 只读取证、结论型，**非实施方案**，为立项做依据。
> **凡「XX调研 / 能力边界 / 可行性 / 现状核查 / 只读分析 / 审计 / 核对报告 / 实测报告」类文档一律落此**，禁止搁 `doc/todo/`。
> **生命周期**：主题立项 → 方案进 `doc/todo/`；方案落地后本文档转过时 → 移入 `doc/chaos/`。
