# 遗留问题台账（常驻，不归档）

> **规则见 `index.md` §7**。本文件**只含未解决问题**；解决后**直接删条目**，解决方式写进对应 ADR / 设计文档 / 代码注释。
> **登记时机**：发现即登记，不攒不拖；方案落地时同步查遗留尾巴，有则补登。
> **为什么常驻**：一旦允许归档，未解决项就会被"归档"掉，下次无人知晓。

## 字段定义

| 字段 | 要求 |
|---|---|
| 编号 | `#N`，全局递增，**删条目后不复用编号**（外部引用不会指错） |
| 问题 | 一句话说清**现象 + 位置**（带 `file:line` 或符号） |
| 来由 | 哪个方案/哪次改动暴露的 |
| 状态 | `未处理 / 待复核 / 已知限制 / 阻塞中` |
| 影响 | 不解决会怎样（**写后果，不写"待优化"**） |
